# Adapt to B2B — другая методология для длинных сделок

> Промпт из этого репо собран под B2C-онлайн-школу: короткий цикл, один ЛПР, поведенческие сигналы важнее всего. Если ты продаёшь в B2B (средний чек $5k+, цикл 1-6 месяцев, 3-5 ЛПР на сделке) — методология сильно другая.

## Что меняется

| Фактор | B2C-онлайн-школа (default) | B2B-сделка |
|--------|---------------------------|------------|
| Цикл сделки | 5-14 дней | 30-180 дней |
| Кол-во ЛПР | 1 | 3-7 |
| Поведенческие сигналы | главное | вторично |
| Fit сигналы | вторично | главное |
| Buying signal в crm_notes | важно | критично |
| Recency | сильное затухание после 14 дней | плавное, до 60 дней |

## Новые веса (B2B)

### 1. Fit signals — 60%

Это главный предиктор в B2B. Если компания не подходит, никакие downloads и webinars не помогут.

- `company_size` ∈ ICP → **+30**
- `industry` ∈ target verticals → **+25**
- `position` соответствует уровню принятия решения (C-level / VP / Head of …) → **+25**
- `geo` ∈ обслуживаемые регионы → **+15**
- Технологический стек совпадает с твоим продуктом (например, у тебя SaaS для Salesforce — у клиента Salesforce) → **+20**

### 2. Buying signals — 25%

Внутри B2B самое ценное — явные сигналы покупательского намерения.

- В `crm_notes` упоминание бюджета, тендера, RFP, сроков → **+30**
- Запросил demo / pricing → **+25**
- Указан timeline («внедряем в Q3») → **+20**
- Упомянул конкурента, у которого они сейчас сидят → **+15** (понятно, кого замещаем)
- Упомянул внутренний проект-инициатор → **+15**

### 3. Engagement quality — 10%

Не количество кликов, а **многоконтактный engagement** — кто-то ещё из компании зашёл.

- ≥ 2 человека из одной компании в воронке → **+25** (комитет формируется)
- Открыли pricing page → **+15**
- Скачали тех. документ (case study, architecture, security) → **+15**
- Запросили sandbox / trial → **+25**

### 4. Recency — 5%

В B2B свежесть менее критична, но всё равно важна.

- ≤ 14 дней с последнего касания → **+15**
- 15-30 дней → **+5**
- 31-60 дней → **0**
- > 60 дней → **−15** (сделка остыла, нужна реактивация)

## Новые колонки в CSV для B2B

К базовым колонкам добавь:

| Колонка | Тип | Пример |
|---------|-----|--------|
| `company_name` | string | АкмеЛогистикс |
| `industry` | enum | logistics / fintech / retail / saas / manufacturing |
| `geo` | enum | KZ / CIS / EU / US |
| `decision_makers_count` | int | 3 |
| `has_budget` | bool | true |
| `timeline_months` | int | 3 |
| `current_solution` | string | «используют Excel» / «конкурент X» |
| `engagement_score_from_marketing` | int 0-100 | 65 |
| `request_type` | enum | demo / pricing / case / consultation / generic |

## Категории B2B (другие пороги)

- **A — Sales Qualified (SQL):** score ≥ 75. Звонок Sales Director в течение 24 часов.
- **B — Marketing Qualified (MQL):** 50 ≤ score < 75. SDR прорабатывает, делает discovery call.
- **C — Nurture:** 25 ≤ score < 50. Cdn-nurture поток на 3-6 месяцев.
- **D — Disqualify:** < 25. Не подходящий ICP, мусор-форма.

## Промпт для B2B (заменить в основном prompt.md)

В оригинальном `prompt.md` замени блок «Контекст компании» и «Методология скоринга» на следующее:

```
## Контекст компании

[ТВОЯ КОМПАНИЯ] — B2B SaaS / интегратор / агентство в [индустрия]. Продаём [продукт] компаниям с [размер] в [регион].
Средний чек: [сумма].
Типичный цикл сделки: [N] месяцев.
Decision unit: [роли — например, COO + CFO + Head of IT].

## ICP (Ideal Customer Profile)

- Индустрии: [список]
- Размер: [employees / revenue]
- Технологический стек: [триггеры]
- Геогр: [список]
- Стадия: [growth / mature / digitizing / etc]

## Методология скоринга

[ВСТАВИТЬ 4 группы из adapt-to-b2b.md выше]

## Категории

A (SQL) ≥ 75
B (MQL) 50-74
C (Nurture) 25-49
D (Disqualify) < 25

## Формат вывода

[как в основном prompt.md, но в TOP-10 для каждого лида:
- кому в компании звонить первым (по доступной информации)
- какой канал использовать (звонок / email / linkedin)
- какой контент дать на первое касание (case study, demo, white paper)
- что в первом сообщении нельзя говорить (например, «не упоминать конкурента X»)]
```

## Что не работает в B2B и почему

- **«Score всех лидов одинаково независимо от канала»** — нет. Лид с outbound через LinkedIn и inbound с pricing page имеют разную природу intent.
- **«Запустить скоринг без enrichment»** — нет. В B2B fit сигналы определяют 60% качества лида. Без обогащения данных компании (industry, size, geo, stack) скоринг — гадание.
- **«Один скоринг на всю воронку»** — обычно стоит сделать **два скоринга**: лида (человека) и аккаунта (компании). Account-based на средний/корп.

## Конкретный B2B-сценарий

Если ты продаёшь, например, AI-инструменты для отделов продаж компаниям в КЗ:

- ICP: компании 50-500 сотрудников, B2B-продажи, со sales-командой 5-30 человек, в логистике / финтехе / SaaS / b2b-услугах.
- Fit-сигналы которые ищем: «head of sales», «commercial director», «CRO», «руководитель коммерческого», «РОП». Indicator vacancies на hh.kz («ищем head of sales») = горячий аккаунт.
- Buying signals: «у нас 6 менеджеров», «делаем 1000 звонков в неделю», упоминание AmoCRM/Bitrix/HubSpot (понятен текущий стек).
- Disqualify: компании < 10 сотрудников, B2C-розница, агентства недвижимости, мелкие ИП.

Этот сегмент попадает в формулу из [adapt-to-b2b.md](adapt-to-b2b.md). Прогон промпта на 100 ваших B2B-лидов даст вам приоритетный список аккаунтов и понятные следующие шаги по каждому.
