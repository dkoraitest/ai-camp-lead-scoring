# Monday Action — поставь скоринг в работу за один рабочий день

> После воркшопа у тебя на руках работающий промпт. Этот файл — как превратить «прогнал один раз на сэмпле» в **«каждое утро в 9:00 на ноуте лежит список «звони сначала этим»**.

## Шаг 1 (15 мин) — выгрузи 100–500 своих свежих лидов из CRM

Тебе нужен CSV с теми же колонками, что в `sample-leads.csv`. Минимальный обязательный набор — **то, что есть в любой CRM**:

- `lead_id`, `created_at`, `source`, `name`, `phone_provided`
- `last_contact_days_ago`, `touches_count` (обычно auto)
- `crm_notes` — главный сигнал. Чем подробнее менеджеры пишут, тем точнее скоринг.

**Опционально (если есть)** — поведенческие сигналы:
- `email_opened_count`, `link_clicked` (нужна интеграция с email-сервисом — Mindbox, Mailchimp, sendpulse)
- `material_downloaded` (нужен tracking на лендинге)
- `webinar_attended_min` (нужна интеграция с вебинарной платформой — Bizon, MyOwnConference)
- `position`, `company_size`, `course_interest` — из формы заявки или после enrichment

**Не страшно, если каких-то колонок нет.** Промпт переключается на адаптивные веса: когда behavior пустой, главным становится `crm_notes`. Один сильный комментарий менеджера типа «входящий звонок, готова оплатить, нужен счёт на ТОО» — это сигнал не хуже, чем 45 минут на вебинаре.

**Главный совет:** если crm_notes у тебя в команде пишут плохо («ок», «перезвонить», пусто) — это первое, что надо чинить. Без этого скоринг половины воронки будет угадыванием.

### AmoCRM
1. Сделки → Фильтр → выбери воронку и статус «Первичный контакт» (или эквивалент)
2. Меню воронки → «Экспорт» → формат CSV
3. Дополни поведенческими сигналами из интеграций (Mindbox / email-сервис / онлайн-чат)

### Bitrix24
1. CRM → Лиды → Список → ⚙ Настройки колонок → добавь все нужные поля
2. Действия → Экспортировать в CSV
3. Поведение — из «Активности» (история взаимодействий) можно посчитать `touches_count`

### HubSpot
1. Contacts → создай view с фильтром "Lead status = New" or "Open"
2. Actions → Export → выбери колонки → CSV
3. Email behavior — встроенный, экспортируется автоматически (`Number of times contacted`, `Last activity date`)

### Salesforce
1. Setup → Data Loader → Export → выбери Lead object
2. Поля: Standard + Custom (включая Engagement-метрики из Pardot если есть)
3. Export → CSV
4. Альтернатива: Reports → создай "Lead Scoring Source" → Export Details

### Pipedrive
1. Leads inbox → Filter → создай сегмент свежих
2. … → Export → CSV
3. Behavior — отдельно из Mailchimp / Mailgun интеграции

## Шаг 2 (5 мин) — адаптируй промпт под себя

В `prompt.md` поменяй 3 места:

### Место 1: «Контекст компании»
Замени параграф про онлайн-школу на свой:
- Что продаёшь, средний чек, цикл сделки
- Откуда лиды приходят
- Кто ICP (idealan customer profile)

### Место 2: «Behavior signals» — веса
Если твои поведенческие сигналы другие, опиши их и расставь веса. Главное правило: **download или участие в долгом контенте >> любое клик/open**. Действие, требующее времени, гораздо ценнее пассивного просмотра.

### Место 3: «Fit signals» — кто твой ICP
Замени `маркетолог / руководитель отдела / без должности` на роли, которые покупают у тебя. Если ты B2B — читай отдельный файл [adapt-to-b2b.md](adapt-to-b2b.md), там методология сильно отличается.

## Шаг 3 (10 мин) — прогон на реальных данных + проверка

1. Запусти промпт в Claude / ChatGPT с твоим CSV.
2. Возьми **TOP-10 от AI** и параллельно попроси **РОПа без AI** дать его TOP-10 интуитивно.
3. Сравни. Где пересечение — это валидация. Где расхождение — самое интересное:
   - Если AI поднял лид, который РОП пропустил → может быть скрытый алмаз
   - Если РОП поднял лид, которого AI занизил → может быть фактор, который не попал в промпт. Добавь его.

Через 2–3 такие итерации промпт калибруется под твою воронку.

## Шаг 4 (1 час) — поставь на cron

Дальше — выбор инструмента. Все три работают, разница в навыках команды.

### Вариант A: Make.com (low-code, рекомендуется)

```
[Cron: ежедневно 8:45]
    ↓
[CRM API: GET свежие лиды за последние 30 дней]
    ↓
[OpenAI/Anthropic: POST chat completion с промптом + CSV]
    ↓
[Парсер: вытащить TOP-10 из ответа]
    ↓
[Telegram бот / Slack / Email: отправить РОПу и менеджерам]
    ↓
[Google Sheet: лог истории скоринга для аудита]
```

Стоимость: ~$10–30/мес (Make Core/Pro + OpenAI API). Время сборки: ~1 час.

### Вариант B: Apps Script + Google Sheets (бесплатно)

Если CRM умеет экспортировать в Google Sheets автоматически:
1. Apps Script триггер ежедневно в 8:45
2. Скрипт читает свежие строки → вызывает OpenAI API → пишет результат в новую вкладку
3. РОП утром открывает таблицу, видит ранжированный список

Стоимость: ~$5/мес (OpenAI API). Время сборки: 2-3 часа.

### Вариант C: n8n (self-hosted, если данные не должны уходить наружу)

То же, что Make, но self-hosted. Полный контроль над данными. Время сборки: ~2 часа + время на настройку сервера.

## Шаг 5 (через 2 недели) — мерь, работает ли

Раздели лидов на 3 групппы по скорингу. Через 14 дней посчитай для каждой:

| Категория | Лидов взяли в работу | Дошли до квалификации | Купили | Conv % |
|-----------|---------------------|----------------------|--------|--------|
| A | … | … | … | целевая >25% |
| B | … | … | … | целевая 8-15% |
| C | … | … | … | целевая <3% |

Если conversion в A < 2x conversion в B → промпт ещё не откалиброван, копай.
Если А-категория конвертируется в 3-5 раз лучше B → скоринг работает, выкатывай на 100% входящих.

## Частые ошибки при внедрении

1. **«Загрузил весь архив за 2 года»** — нет. Скоринг работает на свежем потоке. Старее 30 дней — это уже не приоритизация, это реактивация (отдельная задача).
2. **«Промпт даёт странные оценки»** — почти всегда дело в плохих или пустых данных. CSV без поведения = угадывание. Сначала почини tracking, потом запускай скоринг.
3. **«AI занижает мои любимые лиды»** — спорь, но через данные. Промпт можно настроить под твою интуицию: добавь свои факторы и веса в «Touch quality».
4. **«Команда не доверяет»** — обязательно проси AI **обосновать каждое решение** (это есть в промпте — колонка `top-3 причины`). Когда менеджер видит конкретные «вебинар 45 мин + рассрочка + ≤3 дней», доверие растёт быстро.
